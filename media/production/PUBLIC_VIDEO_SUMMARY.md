# Skill-YT video production summary

The editable Remotion project contains three original motion-graphics compositions about an offline-first, draft-only inbox reference implementation.

| Cut | Duration | Resolution | FPS |
| --- | ---: | --- | ---: |
| Cinematic trailer | 45 seconds | 1920 x 1080 | 30 |
| How Skill-YT Works | 300 seconds | 1920 x 1080 | 30 |
| Portrait short | 27 seconds | 1080 x 1920 | 30 |

The local review exports contain H.264 video, AAC stereo narration and original synthesized sound design. The production uses vector geometry, dimensional interfaces, data paths and kinetic typography. A portrait-specific layout is authored independently. Narration scripts, caption timing and subtitles are included with the editable source. Exact original WAVs are retained locally for a separately approved source archive.

## Verified evidence

Verification was recorded on 20 November 2026 against application commit `d11e78c41db068f476d1b12db35e0f0ea6cbf32f`. Local checks passed 45 Python tests with one dedicated Docker integration test skipped, Ruff, and 12 independent Node tests. The Python demo produced one in-memory draft, two review outcomes and three duplicate skips. The Node example produced two generic acknowledgments pending review, held suspicious content without a draft and skipped the duplicate.

The final videos passed ffprobe metadata checks, SHA-256 comparisons and full FFmpeg decoding. The existing editable archive passed CRC checks. Frame inspection covered 12 trailer frames, 68 explainer frames across every scene/chapter, five portrait frames and full-resolution details. Narration was generated locally. Caption pages follow synthesized sentence timing with proportional timing inside each sentence.

GitHub CI evidence in the [fact check](FACT_CHECK.md) refers to the previously recorded run. The latest remote CI could not be refreshed during local publication preparation. Interactive playback and a perceptual narration listening pass were not independently observed in the restricted preparation environment.

The demonstrations use synthetic data. Live Gmail and external AI-provider integrations remain unverified. The application exposes no agent-accessible send operation. Pattern checks and single-worker draft recovery have the limits described in the [security documentation](../../docs/SECURITY.md). A separate model-backed invocation of the inbox skill remains unverified.
